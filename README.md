# Khayal Jamilli — Portfolio

Premium personal portfolio built with Next.js, TypeScript, Tailwind CSS, and next-intl.

## Features

- Apple-inspired minimal design (dark default + polished light mode)
- Locales: English, Russian, Turkish, German, Azerbaijani
- Featured product: GovMate AI
- Live GitHub repositories section
- Optimized for Vercel deployment

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000/en](http://localhost:3000/en).

## Environment

Copy `.env.example` to `.env.local`:

```bash
GITHUB_USERNAME=xeyal9032
GITHUB_TOKEN=
NEXT_PUBLIC_SITE_URL=https://your-project.vercel.app
NEXT_PUBLIC_CONTACT_EMAIL=xeyalcemilli9032@gmail.com
```

## Scripts

- `npm run dev` — local development
- `npm run build` — production build
- `npm run start` — start production server
- `npm run lint` — ESLint
